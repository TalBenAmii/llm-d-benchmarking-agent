# Source provenance and third-party material

The source archive retains the main Apache-2.0 LICENSE, the project NOTICE, and the licenses
and notices of each packaged upstream repository. `docs/source_manifest.json` in the ZIP
records exact origins, revisions and SHA-256 file hashes. Upstream source is distinguished
from the owned application and standalone MCP adapter.

Installed environments, credentials, model weights, container images and proprietary CLI
binaries are not bundled. Python and CLI dependencies are declared in project manifests,
lockfiles and installation scripts. Dependencies fetched during installation retain their
own terms; the container NOTICE separately identifies the proprietary Claude CLI.

The UI and historical demo include llm-d branding and styles referencing Red Hat fonts.
These are not student-created branding. The project README identifies the llm-d mark and
disclaims affiliation. This inventory records attribution; it does not certify trademark
permissions. The course's public-repository condition requires the author to establish any
needed asset rights, or use private repository sharing. This refresh does not change
repository visibility or claim clearance of those assets.
